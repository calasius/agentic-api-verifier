## Hypothesis

> The mechanic_api field in the request body is used to make an outbound HTTP request with no URL validation, allowlist, or SSRF protection. The response from the target URL is included in the API response body. An attacker can probe internal services, cloud metadata endpoints, and other resources reachable from the workshop container.
