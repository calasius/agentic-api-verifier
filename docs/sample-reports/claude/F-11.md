## Hypothesis

> The gateway service's checkCreds() function hard-codes the credentials vendorcrapi / Pa$$4Vendor_1 directly in source. These credentials protect endpoints that return VIN ownership history (including SSNs, addresses, PII for previous vehicle owners) and payment card information. Anyone with source code access — including any developer or repository viewer — has permanent access to these endpoints.
