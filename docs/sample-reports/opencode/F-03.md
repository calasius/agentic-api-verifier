## Hypothesis

> getKeyFromJkuHeader() opens a URLConnection to the URL found in the jku JWT header with no allowlist, no hostname binding, and no SSRF protection. An attacker generates their own RSA key pair, hosts their own JWKS at an arbitrary URL, embeds that URL in the jku header, and signs the JWT with their private key. The server fetches the attacker's JWKS and uses the attacker's public key to verify the attacker's signature — accepting the forged token as valid.
