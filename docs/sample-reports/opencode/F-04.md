## Hypothesis

> getJwtSecret() sets the HMAC-SHA256 secret to Base64.getEncoder().encodeToString(publicRSAKey.toPublicKey().getEncoded()) — the standard-base64-encoded DER form of the RSA public key. The public key is fully exposed at GET /identity/api/auth/jwks.json. An attacker who switches the algorithm header to HS256 can reconstruct this secret, forge any claims, and produce a valid HMAC signature. A second variant exists: if the kid header contains the string /dev/null, the secret is hard-coded to "AA==" (a trivial near-zero-byte secret).
