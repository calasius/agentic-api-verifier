## Hypothesis

> Vehicle ownership is verified solely by matching VIN + pincode. All five seeded vehicles share the pincode 123456 — a trivially guessable value with no lockout on failed attempts. VINs for other users' vehicles are leaked via the BOLA in F-01. An attacker can enumerate vehicle UUIDs/VINs via F-01, then claim ownership of any vehicle using the shared default pincode.
