## Hypothesis

> Several endpoints are missing authentication entirely. (1) GET /workshop/api/merchant/service_requests/{vin} returns service request records including owner email and phone for any VIN, unauthenticated. (2) GET /workshop/api/shop/orders/{order_id} returns full order details including masked payment card number, card type, and expiry — unauthenticated. (3) POST /identity/api/auth/reset-test-users resets all seeded user passwords without any authentication, providing a denial-of-service capability against all accounts. (4) The entire chatbot service has no authentication on any endpoint, including /genai/init which accepts external LLM API keys.
