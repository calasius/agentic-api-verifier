## Hypothesis

> When the application property ENABLE_SHELL_INJECTION is true, the convert_video flow reads the conversion_params field from the video record (writable by any authenticated user via PUT /user/videos/{id}) and concatenates it unsanitized into: String.format("convertVideo -i %s %s", video_name, conversion_params), then executes the result with Runtime.exec(new String[]{"bash","-c",command}). The convert_video endpoint blocks requests arriving with an x-forwarded-host header (i.e., via the nginx reverse proxy), but the SSRF in F-09 or direct internal network access can bypass this control to reach the endpoint without the proxy header.
